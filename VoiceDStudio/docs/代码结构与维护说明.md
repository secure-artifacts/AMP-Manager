# VoiceDStudio V0.96 代码结构与维护说明

本版没有大幅移动文件路径，主要原因是 Chrome MV3 的 `manifest.json`、`content_scripts`、`world: MAIN` 注入顺序都比较敏感。为了降低回归风险，本版采用“保留文件位置 + 在文件内按功能区块整理 + 补充注释”的方式。

## 文件分类

| 文件 | 分类 | 主要职责 |
|---|---|---|
| `manifest.json` | 插件声明 | 权限、图标、popup、background、content scripts 注入顺序。 |
| `VoiceDStudio.html` | Popup 界面 | 顶部标题、语音/翻译/预设/参数四个 Tab、Google 表格导入入口。 |
| `VoiceDStudio.css` | Popup 样式 | Apple Music / 玻璃拟态主题、卡片、按钮、导入提示、右侧栏相关样式。 |
| `VoiceDStudio.js` | Popup 主逻辑 | 设置保存、TTS 生成、模板预设、Google 表格导入、右侧栏开关。 |
| `background.js` | Service Worker | 消息转发、offscreen 创建、脚本注入、积分刷新。 |
| `offscreen.html` / `offscreen.js` | 音频生成环境 | ElevenLabs / Google TTS 请求、音频缓存、base64 返回。 |
| `VoiceDStudioContent.js` | Content Script 桥接 | popup/background 与页面 MAIN world 音频 Hook 通信。 |
| `pageHook.js` | MAIN world Hook | 捕获 WebRTC 音频 sender、替换混音轨道、注入 TTS。 |
| `pageManager.js` | 页面右侧管理栏 | 通话页面右侧热区、模板/预设列表、朗读、发送文本、宽度拖拽。 |

## 维护建议

1. **改 Popup UI**：优先改 `VoiceDStudio.html` + `VoiceDStudio.css`，按钮事件在 `VoiceDStudio.js`。
2. **改表格导入**：只改 `VoiceDStudio.js` 的 `Google 表格导入` 区块，重点函数是 `fbvdsLoadGoogleSheetAsSheetsV077()` 和 `fbvdsRunSheetImportV077()`。
3. **改右侧管理栏**：优先改 `pageManager.js`，不要把管理栏逻辑重新放回 popup。
4. **改音频注入**：`pageHook.js` 和 `VoiceDStudioContent.js` 风险最高，除非必须，不建议重写。
5. **改版本号**：同时更新 `manifest.json`、`VoiceDStudio.html`、`README_使用说明.txt`、`background.js` / `content` ping 返回版本。
