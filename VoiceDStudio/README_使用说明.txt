FB IG VoiceDStudio V0.95 使用说明

一、核心功能
本版可以把 ElevenLabs TTS 语音直接混入 Facebook / Messenger / Instagram 通话麦克风音轨。

原理：
真实麦克风 track + TTS 音频
→ AudioContext 混音
→ MediaStreamAudioDestinationNode
→ RTCRtpSender.replaceTrack(mixedTrack)
→ 对方直接在通话里听见 TTS 屏蔽原声道，互不影响，实现静音喊麦。

二、安装
1. 解压 VoiceDStudioV0.95.zip
2. 打开 Chrome：chrome://extensions/
3. 开启开发者模式
4. 加载已解压的 VoiceDStudioV0.95 文件夹
5. 刷新 Facebook / Messenger / Instagram 页面
6. 重新进入通话

三、使用
1. 打开插件。
2. 填入 ElevenLabs API Key。
3. 点击「读取声音列表」并选择 Voice。
4. 输入文字。
5. 点击「语音朗读」。

四、重要测试顺序
1. 安装或重新加载插件。
2. 刷新 Facebook / Messenger / Instagram 页面。
3. 重新进入通话。
4. 先点击「启用混音器」。
5. 如果显示已启用，再点击「语音朗读」。

五、参数
- 稳定度：ElevenLabs stability
- 相似度：similarity_boost
- Style：ElevenLabs style
- Speaker Boost：增强声音存在感
- TTS 注入音量：TTS 混音增益
- 真实麦克风音量：真实麦克风混音增益

六、限制
1. 必须捕获到 Facebook WebRTC audio sender。
2. 最好刷新页面后再进入通话。
3. Facebook/WebRTC 会经过 Opus 编码、回声消除、噪声抑制、自动增益，所以不是无损，但比扬声器外放再让麦克风拾音清晰很多。


V0.91 更新：耳机监听输出设备
- 参数页新增「耳机监听」设置：启用耳机监听、监听输出设备、监听音量、刷新设备、请求音频设备权限、测试监听。
- 朗读注入通话时，会额外复制一路声音到选择的耳机输出设备。
- 监听声不走系统默认输出，适合避免被立体声混音录进去。
- 设备列表从当前通话页面读取，避免插件页面和网页页面的 deviceId 不匹配。

V0.92 更新：侧边栏 TTS 支持耳机监听
- 插件内部版本号、标题版本号、manifest 版本号统一更新为 V0.92 / 0.9.2。
- 修复插件页面 TTS 可以耳机监听，但右侧管理栏/侧边栏 TTS 听不到监听声的问题。
- 侧边栏 TTS 现在会读取参数页的“启用耳机监听 / 监听输出设备 / 监听音量”设置。
- 侧边栏注入 TTS 时会把监听参数同步传给当前通话页面的 pageHook，和插件页面 TTS 使用同一套耳机监听逻辑。


V0.93 更新：耳机监听设备保存 + 按钮模式 + 静音临时恢复
- 请求音频设备权限后，会把当前通话页面读取到的监听输出设备列表保存到参数页。
- 选择监听输出设备后，会保存设备 ID 和设备名称，下次打开插件页面会自动恢复之前选择的设备。
- 「启用耳机监听」改为按钮模式，可直接点击按下 / 取消。
- 「启用耳机监听 / 请求音频设备权限 / 测试监听」改为同一行，放在「监听输出设备」上方。
- 「请求音频设备权限」改为蓝绿紫渐变按钮。
- 仅在启用耳机监听时，如果当前通话标签页处于静音状态，会在 TTS 播放前临时取消页面静音；TTS 说完后恢复到原本的静音或未静音状态。
- 未启用耳机监听时，不会更改通话页面静音状态。
- 从本版开始，README 更新说明只新增当前版本条目，不再把历史版本号统一改成最新版本号。

V0.94 更新：右侧管理栏条目交互优化
- 右侧管理栏宽度范围改为：最小 300px，默认 390px，最大 900px。
- 单击条目等同点击右侧朗读按钮；朗读开始时整条条目会闪一下彩色透明渐变，约 3 秒后完全消失。
- 每个条目前增加 ⭐ 收藏按钮；收藏后自动进入固定置顶的 ❤收藏夹 分组，并显示 ❤；再次点击 ❤ 会回到原分组。
- 发送失败或找不到输入框/发送按钮时，自动把文本复制到剪切板，方便手动粘贴。
- 去掉单条删除按钮；分组上的“收起”按钮改为“选择”按钮。
- 点击“选择”后会显示：全选、取消全选、反选、删除；选择模式下单击条目即选中/取消选中，不额外显示复选框。
- 点击正在朗读的同一条目会立即停止；点击其他条目会停止上一个语音并开始当前条目。


V0.95 更新：TTS 切换朗读静音状态同步
- 启用耳机监听时，TTS 播放前会记录通话页最初静音状态。
- 点击其他条目切换朗读时，会停止上一条语音，但不会立即恢复页面静音，避免新条目刚开始就被上一条恢复静音打断。
- 只有最后一条自然播放结束、点击同一条目手动停止、或播放失败时，才恢复到最初静音/未静音状态。
- 未启用耳机监听时，仍然不更改页面静音状态。

V0.96 更新：自动切回倒计时同步 TTS 切换
- 插件内部版本号、标题版本号、manifest 版本号统一更新为 V0.96 / 0.9.6。
- 自动切回默认通道倒计时与“点击其他条目停止上一条并播放当前条目”的逻辑同步。
- 切换条目时会先取消上一条留下的自动切回倒计时，避免上一条倒计时打断当前正在播放的新 TTS。
- 新条目注入成功后，才重新按新条目的 TTS 时长安排倒计时。
- 自动切回默认倒数从 10 秒改为 2 秒。
- 保留之前历史版本更新说明的原始版本号不改。


V0.97 更新：手动停止 TTS 立即切回默认通道
- 插件内部版本号、标题版本号、manifest 版本号统一更新为 V0.97 / 0.9.7。
- 修复手动停止当前语音时只取消自动切回倒计时、不立即切回默认通道的问题。
- 当“启用自动切回”已勾选时，点击同一条目停止当前 TTS 后，会马上切回默认音频通道。
- 点击其他条目切换播放时仍不会立刻切回，避免打断新条目的播放通道。
- 未启用自动切回时，手动停止仍只停止语音，不更改通道。


V0.98 更新：轻量版实时对话翻译
- 翻译页新增「实时对话翻译（轻量版）」卡片。
- 新增手动双按钮模式：「🎙 我来说」和「🎙 对方说」。
- 支持选择我方语言与对方语言。
- 识别一句语音后自动调用 Google 翻译，并复用现有 TTS 朗读译文。
- 显示识别原文、翻译结果和对话记录。
- 新增复制译文、重新朗读、发送到通话输入框按钮。
- 当前版本先做手动模式，后续可继续升级自动检测谁在说话、自动分段、自动朗读。


V0.99 更新：实时对话翻译独立弹窗 + 双麦克风选择
- 翻译页新增“独立弹窗”按钮，可打开真正独立的实时对话翻译 popup 窗口。
- 弹窗可以自由移动，不受插件 popup 小窗口限制。
- 独立弹窗新增“我方麦克风”和“对方麦克风”选择列表。
- 支持请求麦克风权限、刷新麦克风、保存麦克风设备列表。
- 选择我方 / 对方麦克风后会保存，下次打开自动恢复。
- 轻量版仍使用浏览器 Web Speech API，麦克风选择先做保存和权限辅助；真正指定麦克风识别会在后续专业版接入 STT 后实现。
